# Response and stream models

Generated by `sdk-python/scripts/gen_model_tables.py` from the Python SDK's pydantic models. Do not edit by hand: run `docker compose run --rm dev python scripts/gen_model_tables.py` from `sdk-python/`. A unit test fails when this file is out of date. Behaviour around the models (parsing, `raw`, errors) is in `sdk-behaviour.md`.

## Field types

| Type | Wire value | Parsed value |
|------|------------|--------------|
| `Price` | string or number | Decimal; blank or missing is null; non-finite or non-numeric fails the field |
| `StreamPrice` | string or number | as `Price`, and the stream sentinel `42949672.95` (ATO, no price) is null |
| `Volume` | string or number | Decimal (volumes and open interest can exceed 32 bits); parsed like `Price` |
| `Quantity` | string or number | int; integral decimals such as `10.00` are accepted, fractions and booleans fail the field; blank is null |
| `EpochTime` | epoch seconds (string or number) | timezone-aware UTC datetime; `0` or blank is null |
| `ISTDateTime` | text in one of `%H:%M:%S %d-%m-%Y`, `%d-%m-%Y %H:%M:%S`, `%d/%m/%Y %H:%M:%S`, `%d-%m-%Y`, `%d-%b-%Y` | datetime at +05:30; an unknown format is null (logged once per shape, never the value) |
| `str` | string or number | string (JSON numbers become strings) |
| `enum X` | string | member of `X`, or the original string when unknown |
| `secret str` | string | masked in `repr` and logs |

Required: the field must be present (a missing required field fails the record). Lenient: in a lenient record a top-level field that fails validation becomes null and the original value stays in `raw`; a protected key (`norenordno` and `status`; `al_id` on `Gtt` and `TriggeredGtt`) failing fails the whole record (`ResponseParseError`, or `UnknownMessage` on the stream). Unknown wire keys are kept (`extra` fields) on every model.
